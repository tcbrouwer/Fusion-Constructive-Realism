# AGENT.md: Foundational State-Space & Reduction Engine (FCR 2.1)

System architecture specification for the **Foundational State-Space & Reduction Engine** implemented under Fusion Constructive Realism (FCR v2.1). This document serves as the primary system design directive for development within Google Antigravity IDE.

---

## 1. System Vision & Scope

The engine provides a low-level, background-independent, discrete-state simulator for FCR 2.1. It operates natively on $M_n$ discrete relational points, executing single-step lawful mutations $\Sigma_{\text{lawful}} = \{t, d, \mu, v\}$ over causal poset step transitions $T \to T'$, and canonical deduplication via graph hashing.

The architecture is strictly modular to allow seamless future extension into:

* **Contingent Fusion ($f \in \Sigma_{\text{contingent}}$):** Sub-universe boundary fusion under metric equivalence.


* **Dedicated FCR Quantum Computer Simulator:** Sequential and composite execution of $\mathcal{M}_{\text{program}}$ gate topologies on $\mathcal{M}_{\text{data}}$ registers.



---

## 2. Tech Stack & Language Selection

* **Core Engine (C++20 / Rust 1.80+):** Native execution of state graph mutations, matrix updates, capacity projection, and Weisfeiler-Lehman (WL) canonical graph hashing. High concurrency for parallel macro-trajectory branching.


* **Interface & Analysis (Python 3.11+):** PyO3 (for Rust) or pybind11 (for C++) wrappers providing CLI execution, analysis, and probability visualization pipelines.

## 3. Data Structures & Core Types (FCR 2.1)

### `StateQ` (Internal World State $Q \in M_n$)

```cpp
struct StateQ {
    uint32_t n;                         // Number of points in Mn
    std::vector<double> mu;              // Spatial metric matrix mu(i, j) [n x n]
    std::vector<std::complex<double>> C; // Complex correlation matrix C(i, j) [n x n]
    
    // Auxiliary metadata
    uint64_t last_mutation_type;        // ID of last applied mutation
    uint32_t node_capacity_exceeded;     // Flag indicating if S(p) > 1.0
};

```

* **Constraints & Axioms:**
* $\mu(i,i) = 0.0$, $\mu(i,j) \in (0, \infty)$.


* $\vert{}C(i,j)\vert{} \le 1.0$, $C(i,i) = 1.0 + 0.0i$, $C(i,j) = C(j,i)^*$.


* Node Capacity Bound: $S(p) = \sum_{q \neq p} \vert{}C(p,q)\vert{}^2 \le 1.0$.





### `CanonicalState` (Deduplicated Equivalence Class $[Q]$)

* **Reduction Pipeline:**
1. **Global Loop Phase Gauge-Fixing:** Shift all edge phase angles by $e^{-i\Phi_{\text{global}}}$ where $\Phi_{\text{global}} = \arg(\text{Tr}(C^3))$.


2. **Numerical Binning:** Round $\mu$, $\vert{}C\vert{}$, and $\arg(C)$ to fixed precision $\epsilon_{\text{bin}} = 10^{-3}$.


3. **WL Canonical Hash String:** Deterministic string hash generated by Weisfeiler-Lehman graph labeling.

## 4. Module 1: State-Space Trajectory Generator (`fcr_generator`)

### Core Execution Flow

The generator reads an initial state $Q_0$ and expands the macro transition graph $\mathcal{M}$ across poset steps $T_0 \to T_1 \to \dots \to T_k$.

```
                     [ State Q_T ]
                           │
             Check Capacity Violation S(p) > 1.0?
                     ┌─────┴─────┐
                   YES           NO
                    │             │
        Execute Virtual Phase     Advance Poset Step T -> T'
        Venting (M_{1/2}) [1]     Branch lawful mutations:
        Priority W_v = 1.0        - Triangulation (t) [1]
        (No Poset Time Tick)      - Decay & Severing (d) [1]
                    │             - Asymptotic Metric (μ) [1]
                    │                     │
                    └──────────┬──────────┘
                               │
               Canonical Reduction Pipeline [1]:
               1. Global Loop Phase Gauge-Fixing [1]
               2. Float Binning (10^-3) [1]
               3. WL Isomorphism Hashing [1]
                               │
               Write State & Path Count to Disk

```

### Critical Mutation Kinetics & Priorities

1. **Virtual Phase Venting ($\mathcal{M}_{1/2} \in \Sigma_{\text{lawful}}$):**
* **Trigger:** If any $S(p) > 1.0$.


* **Priority:** $W_v = 1.0$, executes **instantaneously without incrementing time step $T$**.


* **Scaling:** $C(p,q) \leftarrow \frac{C(p,q)}{\sqrt{S(p)}}$.


* **Scaled Recoil:**

$$C(p,q) \leftarrow C(p,q) \cdot \exp\left( -i \, \phi_{\text{vent}} \cdot \frac{\sum_{k \neq p} \vert{}C(p,k)\vert{}}{\vert{}C(p,q)\vert{}} \right)$$



where $\phi_{\text{vent}} = \arg\left(\sum C(p,q)\right)$ if above $\epsilon_{\text{cancel}}$, else $\Phi_{\text{global}}$.




2. **Lawful Branching Mutations ($\Sigma_{\text{lawful}}$):**
* **Triangulation ($t$):** For open 2-paths $i \to x \to j$ with $C(i,j)=0$, branch state with $C(i,j) \leftarrow C(i,x) \cdot C(x,j)$. Transition weight $W_t = e^{-\mu(i,j)}$.


* **Correlation Decay ($d$):** $C_{T'}(i,j) = C_T(i,j) \cdot e^{-\gamma_d \mu_T(i,j)}$. Sever edge if $\vert{}C(i,j)\vert{} < 10^{-6}$. Transition weight $W_d = e^{+\mu_T(i,j)}$.


* **Asymptotic Metric Evolution ($\mu$):** $\mu_{T'}(i,j) = \mu_T(i,j) \cdot e^{-\alpha\vert{}C_T(i,j)\vert{}} + \beta(1.0 - \mu_T(i,j))$. Transition weight $W_\mu = \vert{}C_T(i,j)\vert{}$.

* Ancestor tracking: Parent hash list and transition weights $W(m)$.

## 5. Module 2: State-Space Probability Evaluator (`fcr_evaluator`)

### Born-Rule Display Postulate Calculation

The evaluator reads time-step folders ($T_k$), aggregates all convergent trajectory paths $\Gamma \to [Q]$, and computes the observational display probability $P([Q])$:

$$P([Q]) = \frac{\left\vert{}\sum_{\Gamma \to [Q]} A(\Gamma)\right\vert{}^2}{\sum_{[Q'] \in \mathcal{V}_{\mathcal{M}}(T_k)} \left\vert{}\sum_{\Gamma' \to [Q']} A(\Gamma')\right\vert{}^2}$$

where $A(\Gamma) = \prod_{i=1}^k W(m_i)$ is the pure real product of physical mutation weights.

### Python Analysis & CLI Output

A Python CLI interface (`fcr_display.py`) ingests the output files and generates formatted display tables:

```bash
python -m fcr.evaluator --run-id run_001 --time-step 3 --top 10
```

## 6. Extensibility Roadmap (Options 2a & 2b)

### Extension 2a: Sub-Universe Boundary Fusion ($f \in \Sigma_{\text{contingent}}$)

* **Module:** `fcr_fusion`
* **Mechanics:** Ingests two separate world states $Q_A \in M_{n_A}$ and $Q_B \in M_{n_B}$.


* **Condition:** Checks multi-point boundary metric equivalence $\mu_A(a_i, a_j) = \mu_B(b_i, b_j)$.


* **Execution:** Generates fused state $Q_{A \oplus B} \in M_{n_A + n_B}$ with bridge edges $C_{\text{bridge}}$ initialized to $\min(\vert{}C_A\vert{}, \vert{}C_B\vert{})$ and phase sum $\phi_a \cdot \phi_b \pmod{2\pi}$. Fused states feed directly into Generator (Module 1).



### Extension 2b: Quantum Computer Simulator

* **Module:** `fcr_qc`
* **Mechanics:** Instantiates pre-normalized $\mathcal{M}_{\text{program}}$ subgraphs ($X, H, T, \text{CNOT}$) and target data qubits $Q_D \in \mathcal{M}_{\text{data}}$.


* **Sequential Fusion Pipeline:** Automates point-identification boundary fusions ($f$), runs Module 1 single-step kinetics ($t, d, \mu, v$), and evaluates output Bell state branch probabilities using Module 2.
